# ShareShelf – Kullanılacak Teknolojiler

## 1. Proje Hakkında

ShareShelf, kullanıcıların kitaplarını dijital ortamda yönetebilmelerini, kişisel kütüphanelerini oluşturabilmelerini ve fiziksel kitaplarını diğer kullanıcılarla paylaşabilmelerini amaçlayan bir platformdur. Projenin geliştirilmesinde web uygulaması ve mobil uygulama birlikte ele alınacaktır.

Bu doküman, proje kapsamında kullanılacak temel teknolojileri ve bu teknolojilerin kullanım amaçlarını açıklamaktadır.

## 2. Backend Teknolojileri

### Java
Uygulamanın sunucu tarafındaki iş mantığını geliştirmek için kullanılacaktır.

### Spring Boot
REST API geliştirme, kullanıcı ve kitap işlemlerini yönetme, iş kurallarını uygulama ve veritabanı işlemlerini gerçekleştirme amacıyla kullanılacaktır.

### Spring Data JPA
Java nesneleri ile veritabanı arasındaki etkileşimi kolaylaştırmak ve veritabanı işlemlerini yönetmek için kullanılacaktır.

## 3. Veritabanı

### MySQL
Kullanıcılar, kitaplar, kullanıcı kütüphaneleri, okuma listeleri, kitap değerlendirmeleri, alıntılar ve fiziksel kitap paylaşımı ile ödünç alma süreçlerine ait verilerin saklanması için kullanılacaktır.

## 4. Web Frontend Teknolojileri

### HTML
Web arayüzünün temel yapısını oluşturmak için kullanılacaktır.

### CSS
Web arayüzünün tasarımını, sayfa düzenini ve görsel özelliklerini oluşturmak için kullanılacaktır.

### JavaScript
Web arayüzündeki etkileşimleri sağlamak ve backend tarafından sunulan REST API'lerle iletişim kurmak için kullanılacaktır.

## 5. Mobil Uygulama Teknolojileri

### React Native
ShareShelf'in Android ve iOS cihazlarda çalışabilecek mobil uygulamasını geliştirmek için kullanılacaktır. Bileşen tabanlı yapısı sayesinde mobil ekranlar ve kullanıcı etkileşimleri oluşturulacaktır.

### JavaScript
React Native ile geliştirilecek mobil uygulamanın temel programlama dili olarak kullanılacaktır.

## 6. API ve Test Araçları

### Postman
Backend API uç noktalarını test etmek, istek ve yanıtları incelemek ve geliştirilen işlevlerin doğruluğunu kontrol etmek için kullanılacaktır.

### Swagger / OpenAPI
REST API uç noktalarını dokümante etmek ve API'leri tarayıcı üzerinden inceleyip test edebilmek için kullanılacaktır.

## 7. Sürüm Kontrolü ve Proje Yönetimi

### Git
Proje kodundaki değişiklikleri takip etmek ve sürüm geçmişini yönetmek için kullanılacaktır.

### GitHub
Kaynak kodlarını barındırmak, proje dokümantasyonunu saklamak, milestone'ları takip etmek ve geliştirme sürecini düzenli şekilde yönetmek için kullanılacaktır.

## 8. Teknoloji Seçimlerinin Geliştirilmesi

Proje ilerledikçe ihtiyaçlara göre yeni teknolojiler veya kütüphaneler eklenebilir. Yapılacak değişiklikler bu dokümanda güncellenecek ve kullanılan teknolojilerin proje kapsamındaki görevleri açıkça belirtilecektir.
